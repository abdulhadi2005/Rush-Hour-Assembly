# Taxi Run - Assembly Language Game
A low-level 2D arcade game developed in x86 Assembly Language as part of the Computer Organization & Assembly Language (COAL) course.

## 🕹️ Project Overview
This project is a taxi simulation game where the player navigates a grid-based city to pick up and drop off passengers while avoiding obstacles and other cars.

## 🚀 Features
- **Dynamic Board:** 35% buildings and 65% roads, generated randomly.
- **Two Taxi Types:** - **Red Taxi:** Faster but higher penalty for hitting obstacles.
  - **Yellow Taxi:** Slower but more durable.
- **Scoring System:** Points awarded for successful drops; penalties for hitting people or obstacles.
- **Increasing Difficulty:** Speed increases every time two passengers are dropped.
- **Graphics:** Developed using video memory and interrupts to create a custom UI.

## 🛠️ Tech Stack
- **Language:** x86 Assembly Language (.asm)
- **Tools:** MASM
